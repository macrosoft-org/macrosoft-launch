# Launcher v11: o Java ficou mais fácil

Agora o launcher resolve sozinho a maioria dos problemas com Java.

- Ao clicar em **Preparar**, ele verifica o Java da modpack.
- Se o caminho estiver errado, ele procura outro Java 8 disponível no launcher
  ou no computador.
- Ao entrar no jogo, ele também verifica se o CloudScript está funcionando.
- Se uma tentativa falhar, ele experimenta outro Java disponível.
- Se nenhum funcionar, você poderá escolher e baixar um Java pela tela **Java**.

O Java baixado fica dentro da pasta do Macrosoft e é configurado automaticamente.
Ele não altera o Java do seu computador.

## O que preciso fazer?

1. Clique em **Preparar**.
2. Clique em **Jogar**.
3. Se aparecer um aviso, confirme e escolha um Java 8 para baixar.
4. Quando terminar, clique em **Jogar** novamente.

Pronto. O launcher cuida do caminho e das verificações.

O botão **Detectar JAVA** continua disponível para quem quiser usar manualmente
um Java que já esteja instalado no computador.
